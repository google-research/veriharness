# Settling a split between written answers

When written answers disagree, their arithmetic and reasoning are usually each internally
sound. They differ in which material they worked from, which provision they took to govern,
and which question they answered. Settle those, from the task's materials, and the rest follows.

## Which source

1. **The task's own words name the file.** `find workspace/ -iname` for every file and sheet
   whose name matches the phrase the task uses. When the task says "the five-year forecast"
   and a file is literally called that, it is the source, including when the file another
   candidate chose is larger, more detailed, more recent or higher-versioned. A case for why
   the differently-named file is better is a case against the candidate that used it.
2. **Provenance settles which of several versions is canonical.** Search the mail, chat and
   calendar stores for the file being sent, approved or called the supporting model. A
   delivered-and-approved version beats a stray higher-numbered one.
3. **A figure the materials state beats one a candidate derived**, and the precise source
   beats the rounded one: a labelled row, an invoice amount, a full-precision workbook value
   over its two-decimal export.
4. **A provided document nobody else opened can decide the split.** For each file the task
   supplies, check which candidates actually used it (their trajectories show what they
   read); one field in it routinely flips the conclusion.

## Which provision

5. **Read the provision's own scoping language** and identify the role each party holds in
   the relationship the task asks about. A rule addressed to one party does not govern the
   other's obligation.
6. **An express clause in the instrument outranks a general doctrine.** Where one candidate
   argues the background rule and another reaches the agreement's own clause on the subject,
   read that clause: does it reach the obligation, does anything carve it out.
7. **Enumerate a clause in full before accepting that something is not covered**, and read
   a narrow clause for exactly what it lists.

## Which question

8. **Take the posture the task asks for.** When the brief is written for one side, a
   candidate that answers from that side's position is answering the question; a neutral or
   opposing framing is not, even when every proposition in it is true.
9. **Grep the governing document for the task's own operative phrase.** The clause that uses
   those words is usually the ground the question turns on; the candidate that reached it
   outranks the one that argued a neighbouring clause well.
